# Contributing

Thanks for your interest in contributing to `uselessbutcool`.

## Development

1. Install dependencies with `npm install`.
2. Start the app with `npm run dev`.
3. Build before opening a PR with `npm run build`.

## Pull Requests

1. Create a branch from `main`.
2. Keep changes focused and easy to review.
3. Explain what changed and how to test it.

## Assets

- Do not commit copyrighted audio you do not have permission to share.
- Keep large media additions intentional and documented.
